# Omafolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Omarchy bar-widget plugin that rotates live prices through the bar and opens a panel showing a stock, fund and crypto portfolio valued in a chosen base currency.

**Architecture:** Pure ES modules in `lib/` hold all logic. Providers turn intentions into request descriptions and parse responses; `market.mjs` decides freshness and scheduling; `portfolio.mjs` values holdings. `MarketService.qml` is the only I/O layer (curl via `Process`, files via `FileView`), and the QML UI reads from it.

**Tech Stack:** QML on Quickshell 0.3.1 / Qt 6.11 inside `omarchy-shell`; JavaScript ES modules (`.mjs`) with JSDoc types; `node --test` (Node 26) for tests; TypeScript `tsc --checkJs` for type checking; curl.

**Spec:** `docs/superpowers/specs/2026-10-10-omafolio-design.md`

## Global Constraints

- Plugin id `bonavr.omafolio`; manifest `schemaVersion: 1`, `kinds: ["bar-widget"]`, `entryPoints.barWidget: "BarWidget.qml"`.
- No build step. The repository is exactly what runs. Dev dependencies (TypeScript) only.
- Everything in `lib/` is pure: no network, no file I/O, no `Qt.*` globals. Time is always a parameter (`now`, in ms).
- Asset references: `crypto:<coingecko-id>` routes to CoinGecko; anything else is a Yahoo symbol.
- Refresh: `refreshSeconds` default 60, minimum 60. Closed Yahoo markets poll every 15 minutes. Backoff 60 s doubling, capped at 15 minutes. Stale after 3 minutes of provider failure.
- Files: holdings `~/.local/share/omafolio/portfolio.json` (mode 600); quote cache `~/.cache/omafolio/quotes.json` (mode 600); settings in the widget's `shell.json` entry.
- Requests: `curl --max-time 15`, body cap 2 MiB, no cookies, user agent `Mozilla/5.0`.
- No API keys, no telemetry, nothing but ticker symbols leaves the machine.
- UI colours come from the theme (`Color` from `qs.Commons`), never hard-coded hex. Arrows have a space before the number (`▲ 1.4%`).
- Spec deviations recorded here: tests use `node --test` rather than `bun test`, because Node is installed and needs nothing extra. `omarchy plugin validate` runs in `npm run check` locally, because CI runners have no Omarchy.

## Review Focus

1. **All requested Yahoo symbols unknown.** Yahoo answers HTTP 404 instead of an empty batch. Expected: those assets become `missing`; the provider is not marked failing and does not back off. Test in Task 3.
2. **Holdings with zero quantity or zero cost.** Expected: value 0, gain percentage `null` (rendered "—"), never `Infinity` or `NaN`. Test in Task 6.
3. **The same asset twice in a hand-edited `portfolio.json`.** Expected: merged into one position, quantities summed and cost weighted, when the cost currencies match; otherwise kept as two rows. Test in Task 7.
4. **A bar item that is neither held nor watched** (the default `crypto:bitcoin`). Expected: it is still fetched. Test in Task 5.
5. **Base currency equal to an asset's currency, and crypto in any base currency.** Expected: no FX pair is requested for either. Test in Task 5.
